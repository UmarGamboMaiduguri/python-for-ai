Student Performance Analyzer 📊🐍

A beginner-friendly Python project that calculates a student's total score, average score, and grade based on three subjects.

🎯 Project Purpose

This project was created as part of my journey to strengthen my Python programming fundamentals for Artificial Intelligence, Machine Learning, and Computer Science.

🛠️ Technologies

- Python 3
- Conditional statements
- User input
- Variables
- Arithmetic operations
- Basic data processing

📚 What I Learned

- How to receive input from users
- How to convert input into numbers using "float()"
- How to calculate totals and averages
- How to use "if", "elif", and "else"
- How to format output using f-strings

▶️ How to Run

python main.py

The program asks for:

1. Student name
2. Math score
3. English score
4. Computer Science score

It then displays the student's total score, average, and grade.
